# دليل Hoshi بالعربية — افهم كل جزء من المحاكي

هذا دليل واجهة Hoshi 0.8. أسماء الأزرار والحقول بالإنجليزية كما تظهر في البرنامج، والشرح بالعربية. بعض الحقول لا تظهر إلا عند اختيار القطعة المناسبة. اسم خاصية داخلي مثل `outerRadius` قد يظهر بعنوان `Outer Radius`.

عند تفعيل وضع الزوار العام، يفتح المصمم دون كلمة مرور، ولكل متصفح مساحة منفصلة مؤقتة. كلمة مرور المالك تفتح مشاريعه الخاصة من Engine connection. مساحة الزائر صالحة حتى 24 ساعة وقد تضيع عند إعادة تشغيل الخادم؛ احتفظ بملفات Export.

الفكرة الأساسية: تصف الصاروخ في `Design workspace`، وتحدد المحركات وظروف التجربة في `Flight Simulation`، ثم تقرأ ما حسبه المحرك. الرسم وحده لا يعني وجود محرك، واختيار مادة لا يثبت قوة القطعة في الواقع.

لشرح الفيزياء وراء هذه الحقول، اقرأ [The science behind it](science-ar.md).

### التعامل مع Hierarchy وScene

| العنصر | كيف تستخدمه؟ |
| --- | --- |
| Hierarchy / Rocket assembly | شجرة القطع. الإزاحة إلى الداخل تعني أن القطعة تابعة للأب الموجود فوقها. |
| Stage / group | حاوية تجميع. لا تملك بالضرورة شكلاً صلباً مستقلاً. |
| empty | الحاوية ليس فيها أجزاء؛ لا يعني أن الرسم تعطّل. |
| Add component | المكان الأساسي لإضافة قطعة. اختر النوع ثم الأب المناسب ثم أكد الإضافة. |
| Attach to | القطعة أو الحاوية التي ستحمل الجزء الجديد. الزعنفة مثلاً ترتبط عادةً بأنبوب الجسم. |
| Search components | بحث عن نوع القطعة، وليس عن محرك دفع. |
| Airframe / Fins / Recovery / Internal & guides / Assemblies | تصنيفات القطع لتسهيل البحث. |

| Duplicate / Copy / Paste | نسخ قطعة أو لصقها في مكان متوافق. راجع ما إذا كانت النسخة تحتوي أجزاء تابعة. |

| سحب صف داخل Hierarchy | إعادة الترتيب أو النقل إلى أب متوافق. لا يمكن جعل القطعة ابناً لنفسها أو لأحد أبنائها. |
| سحب قطعة في Scene | أجزاء البدن الخارجية تعيد ترتيبها؛ بعض القطع الداخلية والزعانف تغيّر موضعها المحوري. تُحفظ الحركة عند الإفلات. |
| سحب الخلفية | تحريك مجال الرؤية؛ لا يغيّر موقع القطع هندسياً. |
| عجلة الفأرة / − / + | تكبير الرسم وتصغيره؛ لا يغيّر أبعاد الصاروخ. |
| Fit / F | ملاءمة الرسم لمساحة العرض. |
| 2D side view | إسقاط جانبي توضيحي. القطع الداخلية قد تتراكب؛ الرسم ليس مخطط تصنيع دقيقاً. |
| الفواصل بين اللوحات | اسحبها لتوسيع Inspector أو Scene. على الهاتف اختر Scene أو Hierarchy أو Inspector من الألسنة. |

## 4. الأرقام تحت الرسم: الكتلة والتوازن

| الاسم | كيف تقرأه؟ |
| --- | --- |
| Dry mass | الكتلة الجافة المحسوبة للهيكل وفق النموذج، دون كتلة محركات الإطلاق. |
| Loaded mass | الكتلة المحمّلة عند البداية للتكوين المختار، بما فيه المحركات. الفارق لا يمثل الوقود فقط؛ المحرك يشمل الغلاف وغيره. |
| CG / Centre of gravity | مركز الثقل: موضع توازن الكتل. يتغير إذا نقلت حمولة أو غيّرت المحرك. |
| CP / Centre of pressure | مركز تأثير القوى الهوائية وفق شروط الحساب. ليس نقطة توازن الكتل. |
| Stability · M 0.3 | هامش استقرار مرجعي عند Mach 0.3؛ ليس فحصاً لكل لحظات الطيران. |
| cal / calibers | قياس الاستقرار بوحدات قطر مرجعي للصاروخ، وليس بالسعرات الحرارية. |
| Configuration | تكوين المحركات والمراحل النشطة الذي تعرضه الرسمة. قد يختلف عن تكوين تجربة محفوظة. |
| No motors / No motor configuration | لا يوجد دفع محدد في التكوين المعروض. |
| Inspect design / warnings | فتح تفاصيل الفحص أو التحذيرات. |

في صاروخ تقليدي مثبت بالزعانف، وجود CG أمام CP يساعد عادةً على الاستعادة بعد اضطراب صغير. لكن الهامش الموجب وحده لا يضمن رحلة مستقرة. كثرة وزن المقدمة أو زيادة مساحة الزعانف ليست حلاً عاماً لكل مشكلة.

## 5. Inspector: الاسم والأبعاد والشكل

اضغط على القطعة أولاً. اكتب القيمة ثم اضغط Enter أو اخرج من الحقل لتطبيقها. انتبه للوحدة المكتوبة بجانب كل قيمة. لا تفترض أن الرقم يعني mm إذا كان الحقل يقول m أو g أو kg/m².

| الحقل | الشرح |
| --- | --- |
| Name | تسمية القطعة لتتعرف عليها. تغيير الاسم لا يحول نوعها إلى قطعة أخرى. |
| Search component settings | تصفية الحقول الظاهرة بكلمة مثل diameter أو mass أو finish. لا يبحث عن قطعة جديدة. |
| Dimensions & shape | قسم الأبعاد الفيزيائية والشكل. |
| Length | الطول باتجاه محور الصاروخ. إذا أدخلت 200 mm فالمقصود 20 cm. |
| Outer Diameter / outerDiameter | القطر الخارجي الكامل للأنبوب. |
| Outer Radius / outerRadius | نصف القطر الخارجي. قطر 30 mm يعني نصف قطر 15 mm، وليس 30 mm. |
| Inner Diameter / innerDiameter | القطر الداخلي للفتحة. |
| Inner Radius / innerRadius | نصف قطر الفتحة الداخلية. |
| Radius / radius | نصف قطر القطعة المعنية. |
| Diameter / diameter | القطر؛ في Parachute يكون قطر المظلة المنشورة. |
| Thickness | سماكة جدار الأنبوب أو مادة الزعنفة، وليست القطر. |
| Base Diameter / baseDiameter | القطر عند قاعدة المقدمة. |
| Base Radius / baseRadius | نصف قطر قاعدة المقدمة. |
| Fore Diameter / foreDiameter | قطر الطرف الأمامي من الوصلة. |
| Fore Radius / foreRadius | نصف قطر الطرف الأمامي. |
| Aft Diameter / aftDiameter | قطر الطرف الخلفي. |
| Aft Radius / aftRadius | نصف قطر الطرف الخلفي. |
| Shape Type | نوع منحنى المقدمة أو الوصلة، مثل شكل مخروطي أو منحنى آخر متاح. |
| Shape Parameter | معامل يعدّل المنحنى المختار؛ معناه وتأثيره يعتمدان على Shape Type. |
| Filled | اعتبار القطعة مصمتة بدلاً من مجوفة. يزيد المادة المحسوبة عادةً. |
| Clipped | خيار قص هندسي خاص بنوع القطعة؛ ليس حذفها من المشروع. |
| Flipped | عكس اتجاه القطعة التي تدعم هذا الخيار. |
| Area | مساحة تستخدمها هندسة القطعة أو نموذجها؛ راجع نوع القطعة قبل تفسيرها. |
| Aspect Ratio | نسبة أبعاد مرتبطة بهندسة القطعة، وليست طولاً بوحدة mm. |
| Packed Length / Packed Radius | الحيّز الذي تشغله أداة الاسترجاع وهي مطوية، بخلاف حجمها عند النشر. |

لأنبوب دائري منتظم: سماكة الجدار تساوي تقريباً الفرق بين نصف القطر الخارجي والداخلي. واجهة هذه القطعة قد تربط هذه القيم؛ لا تتعامل معها كأرقام مستقلة دائماً. أنبوب بقطر صفر ليس أنبوباً مرئياً صالحاً، ولذلك يوجد تنبيه إصلاح عند اكتشافه.

## 6. Material & density: المادة ليست لوناً

| الحقل | الشرح |
| --- | --- |
| Material & density | المادة والكثافة اللتان تدخلان في حساب الكتلة. |
| Material library | اختيار مادة من مكتبة OpenRocket. |
| Custom / current material | استخدام المادة الحالية أو إدخال مادة مخصصة. |
| Material name | اسم وصفي للمادة، لا يغير خصائصها وحده. |
| Density | مقدار الكتلة لكل حجم أو مساحة أو طول، حسب نوع المادة. |
| BULK / kg/m³ | كثافة حجمية، مثل مادة أنبوب أو زعنفة. |
| SURFACE / kg/m² | كتلة لكل مساحة، مثل قماش المظلة. |
| LINE / kg/m | كتلة لكل طول، مثل الحبل. |
| Apply material | تطبيق الاسم والكثافة المختارين. اختيار اسم في القائمة قبل التطبيق لا يكفي دائماً لتعديل المشروع. |
| Automatic sizing | أحجام تتبع هندسة قطع مجاورة أو علاقة هندسية. |
| Outer Radius Automatic | جعل نصف القطر الخارجي يتحدد تلقائياً. ألغِه إن احتجت نصف قطر ثابتاً. |
| Inner Radius Automatic | تحديد نصف القطر الداخلي من العلاقات الهندسية المتاحة. |
| Base Radius Automatic | مطابقة نصف قطر قاعدة المقدمة تلقائياً. |
| Fore Radius Automatic / Aft Radius Automatic | مطابقة الطرف الأمامي أو الخلفي تلقائياً. |
| Radius Automatic | تحديد نصف القطر آلياً في نوع القطعة الذي يدعم ذلك. |

اختيار مادة كثيفة يجعل الكتلة المحسوبة مختلفة، لكنه لا يحوّل البرنامج إلى اختبار لقوة المادة أو جودة الغراء. الكثافة ومقاومة الكسر خاصيتان مختلفتان.

| AFTER / After previous component | وضع القطعة بعد السابقة في ترتيب التجميع. |
| TOP / From parent front | القياس نسبةً إلى بداية القطعة الأم. |
| MIDDLE / From parent middle | المرجع منتصف الأب. |
| BOTTOM / From parent rear | المرجع نهاية الأب. |
| Axial Offset | الإزاحة عن المرجع المختار. علامة الرقم وتأثيره يعتمدان على المرجع. |
| Radial Position | البعد عن محور الصاروخ. |
| Radial Direction | الاتجاه حول المحور الذي تقع فيه الإزاحة. |
| Base Rotation | تدوير مجموعة القطع حول محور الصاروخ. |
| Radius Method / Radius Offset | مرجع الإزاحة الشعاعية وقيمتها للقطع الجانبية أو المتكررة. |
| Angle Method / Angle Offset | مرجع الوضع الزاوي والإزاحة عنه. |
| Angle Separation | الزاوية بين النسخ المتكررة. |
| Instance Count | عدد النسخ الهندسية للقطعة أو المجموعة. |
| Instance Separation | المسافة بين النسخ. |
| Move to a different parent | تغيير الأب إلى قطعة متوافقة؛ لا يغير المكان في الشجرة فقط، بل قد يغير المرجع الهندسي. |

في Nose cone وBody tube وTransition، يتبع الموضع الخارجي ترتيب التجميع في هذه النسخة. لذلك تكون بعض حقول Axial Method وAxial Offset للقراءة فقط. حرّكها بالسحب أو إعادة الترتيب، بدلاً من انتظار تأثير حقل معطّل.

## 9. المحركات والتكوينات والمراحل

هناك ثلاثة أشياء منفصلة: `Motor mount` هو الحامل، و`Motor` هو مصدر الدفع الذي تختاره، و`Configuration` يحدد أي محركات ومراحل تعمل في تجربة معينة. قد يكون الأنبوب حامل محرك، لكنه يبقى بلا دفع حتى تعيّن له محركاً فعلياً.

| الاسم | معناه |
| --- | --- |
| Motor mount | السماح للأنبوب بحمل محرك. |

| Search motors | البحث باسم الشركة أو رمز المحرك. |

| Total impulse [N·s] | تكامل الدفع مع الزمن؛ ليس الدفع اللحظي. |
| Launch mass [g] | كتلة المحرك عند بداية التشغيل. |

| Source description | وصف مصدر البيانات؛ مهم لتتبع المنحنى المستخدم. |

| Ignition Event / Ignition Delay | الحدث الذي يبدأ تشغيل المحرك والتأخير بعده، خصوصاً للمراحل. |

| Stage separation | إعداد انفصال مرحلة. |

الحروف والأرقام في رموز المحركات تتبع اصطلاحات المحركات المعنية؛ لا تختَر اعتماداً على رقم أكبر فقط. المحاكي يتحقق من بعض شروط الملاءمة الهندسية، لكنه لا يفحص التثبيت المادي على صاروخك.

## 10. Recovery deployment: متى يفتح نظام الاسترجاع؟

| الحقل | الشرح |
| --- | --- |

## 12. Flight controls: كل سطر من شروط الإطلاق

| الحقل | معناه وكيف تستخدمه |
| --- | --- |
| Use standard atmosphere / ISAAtmosphere | استخدام جو معياري مرجعي. عند تفعيله تكون حقول الحرارة والضغط المخصصين معطلة. ليس قراءة لطقس اليوم. |
| Align launch guide into wind / launchIntoWind | جعل اتجاه الدليل يتبع اتجاه الريح وفق المحرك. عند تفعيله لا تعدّل Guide direction يدوياً. |
| Earth model / geodeticComputation | نموذج إحداثيات الأرض والحركة بالنسبة إليها. |
| FLAT | تقريب أرض مستوية؛ لا يحسب Coriolis ضمن هذه الاستراتيجية. |
| SPHERICAL | أرض كروية مع حساب Coriolis. |
| WGS84 | تمثيل إهليلجي للأرض وحساب Coriolis. لا يعالج وحده أخطاء الوزن أو الريح. |
| Wind model / windModelType | اختيار ريح متوسطة أو ملف متغير مع الارتفاع. |
| AVERAGE | استخدام المتوسط والتغير واتجاه الريح. |
| MULTI_LEVEL | استعمال طبقات رياح بارتفاعات وسرعات واتجاهات مختلفة؛ تحرر من الإعدادات المتقدمة. |
| Launch guide length [m] / launchRodLength | طول الدليل الذي يقيّد الصاروخ في بداية التسارع. 1 هنا تعني متراً، لا mm. |
| Guide tilt from vertical [°] / launchRodAngle | الميل عن العمودي؛ الصفر يعني عمودياً. |
| Guide direction [°] / launchRodDirection | اتجاه الميل حول الأفق؛ ليس مقدار الميل. |
| Site altitude [m] / launchAltitude | ارتفاع موقع الإطلاق فوق سطح البحر. |
| Site latitude [°] / launchLatitude | خط العرض بين −90 و90 درجة. |
| Site longitude [°] / launchLongitude | خط الطول بين −180 و180 درجة. |
| Air temperature [K] / launchTemperature | درجة الحرارة بالكلفن. 20°C تساوي 293.15 K، فلا تدخل 20 وأنت تقصد 20°C. |
| Air pressure [kPa] / launchPressure | الضغط المطلق عند الموقع. بعض تقارير الطقس تعطي ضغطاً مصححاً إلى سطح البحر؛ ليس دائماً القيمة المطلوبة هنا. |
| Maximum flight duration [s] / maxSimulationTime | الحد الأقصى للزمن الذي سيحسبه المحرك؛ ليس مدة الرحلة التي تتوقعها أو تفرضها. الوصول للحد قبل الهبوط قد يعطي رحلة غير مكتملة. |
| Solver time step [s] / timeStep | مقياس الخطوة الزمنية لتكامل الطيران الحر. ليس سرعة الفيديو ولا طول مدة الطيران. تغييره قد يغيّر الدقة العددية وزمن الحساب. |
| Maximum Step Angle / maximumStepAngle | حد التغير الزاوي العددي. للقراءة فقط لأن صيغة الحفظ الأصلية في النسخة المثبتة لا تحتفظ بتعديله. |
| Random Seed / randomSeed | يتحكم في جزء من العشوائية. لا يضمن إعادة جميع تفاصيل الريح المضطربة. |

| Wind direction [°] | الاتجاه الزاوي للريح. طابق اصطلاح الاتجاه في المحرك مع مصدر بياناتك، ولا تفترض اتجاه حركة الصاروخ. |
| Set calm wind | يجعل المتوسط والتغير صفراً في وضع AVERAGE. هذا افتراض تعليمي، وليس قياساً للجو. |
| Wind levels / Wind profile | ملف الطبقات: altitude وspeed وdirection وstandardDeviation. |
| Wind altitude reference | هل ارتفاع طبقة الريح نسبة إلى الأرض/الموقع أم إلى سطح البحر وفق الخيار المعروض. |

مثال لفهم الفرق: صاروخ موقعه على ارتفاع 500 m فوق البحر، ثم يصعد 100 m فوق نقطة الإطلاق، تكون قيمة ارتفاعه فوق موقع الإطلاق 100 m، لا 600 m. لا تخلط بين مرجعَي الارتفاع.

## 13. Flight results: كيف تقرأ النتيجة؟

`Simulation` هي إعداد التجربة، و`Run` تنفيذ واحد لها. تشغيل التجربة بعد تعديل الريح أو الصاروخ ينشئ نتيجة جديدة. لا تستعمل نتيجة قديمة لتقييم تصميم جديد.

| Run record | تنزيل JSON يضم سجل الحساب ومدخلاته المحفوظة، ومنها مصدر التصميم. ليس بديلاً عن قراءة التحذيرات. |

### أهم الأحداث والمتغيرات

| الرمز أو الحدث | تفسيره |
| --- | --- |
| t | الزمن بالثواني. |
| h | الارتفاع فوق موقع الإطلاق بالمتر. |
| Vt | مقدار السرعة الكلية. |
| At | مقدار التسارع الكلي. |
| Px / Py | إحداثيات أفقية في مرجع المحرك؛ Px شرقاً وPy شمالاً في المرجع المحلي المستخدم. |
| Θ / Φ | زاويتا اتجاه الجسم المسجلتان؛ ملفات البيانات تستخدم rad. Θ ارتفاع المحور عن الأفقي وΦ اتجاهه حول الأفق وفق تعريف المحرك. |
| LAUNCH / IGNITION | بداية تسلسل الرحلة أو اشتعال محرك. |
| LAUNCHROD | مغادرة دليل الإطلاق. |
| BURNOUT | انتهاء دفع محرك. لا يعني الوصول إلى أعلى نقطة. |
| APOGEE | قمة المسار. قد تبقى سرعة أفقية حتى عندما تكون السرعة العمودية صفراً. |
| EJECTION_CHARGE | حدث إخراج المحرك كما يمثله النموذج. |
| RECOVERY_DEVICE_DEPLOYMENT | نشر أداة الاسترجاع. |
| STAGE_SEPARATION | انفصال مرحلة. |
| TUMBLE | انتقال إلى نموذج تدحرج/انقلاب تقريبي، وليس عرضاً دقيقاً لكل دورات الجسم. |
| GROUND_HIT | وصول الفرع إلى الأرض. |
| SIM_ABORT | إيقاف بسبب شرط مانع؛ التفاصيل هي التي تشرح لماذا. |
| SIMULATION_END | نهاية الحساب؛ راجع الأحداث السابقة لمعرفة هل اكتملت الرحلة. |

مثال قراءة: ارتفاع 120 m وسرعة كلية 8 m/s لا يخبرك وحده هل الصاروخ صاعد أو نازل. افحص تغير الارتفاع مع الزمن أو مركبة السرعة العمودية والأحداث.

## 16. أول تجربة لفهم البرنامج

1. افتح A simple model rocket، واترك المحركات والإعدادات الأصلية في البداية.
2. اختر Body tube من Hierarchy. لاحظ أن Inspector أصبح يخص الأنبوب نفسه.
3. اقرأ Length وOuter Diameter وThickness وMaterial. سجّل Dry mass وLoaded mass وStability.
4. غيّر Length وحده تغييراً صغيراً ثم Enter. راقب الرسم والأرقام. استخدم Undo لإعادة المقارنة.
5. افتح Flight Simulation وحدد تجربة مرتبطة بتكوين فيه محرك.
6. اقرأ Launch checks وFlight controls. سجّل الافتراضات قبل التشغيل.
7. اضغط Run flight simulation أو Simulate launch بحسب العرض، وانتظر النتيجة الحقيقية.
8. افتح Events وابحث عن BURNOUT وAPOGEE ونشر الاسترجاع وGROUND_HIT إن حدثت.
9. شغّل Recorded rocket flight. غيّر Playback speed لتلاحظ أنه يغيّر العرض لا نتيجة الارتفاع.
10. غيّر عاملاً واحداً فقط في تجربة لاحقة، ثم Compare. احفظ .ork وCSV وRun record عند الحاجة.

لكي تفهم سبب الفرق، لا تغيّر الطول والمادة والمحرك والريح في الوقت نفسه. فصل المتغيرات أسلوب للتعلّم والتحقق، وليس إثباتاً بأن الحالة الأولى تمثل الواقع.

## 17. ما الذي تحسبه المحاكاة، وما الذي يبقى خارجها؟

تحسب النسخة المثبتة من OpenRocket نموذج حركة جسم صلب وقوى هوائية مقدّرة ومنحنى دفع وكتلة متغيرة وجواً وريحاً وأحداث مراحل واسترجاع. أثناء الاسترجاع والتدحرج تستخدم نماذج تقريبية مختلفة، ولا تحسب كل تفاصيل اتجاه الجسم أو انفتاح القماش.

لا يثبت اختيار مادة أن الجدار أو الزعنفة أو الغراء سيتحمل الأحمال. ولا يثبت Completed أن البناء الحقيقي آمن أو أن طقس الموقع مناسب. يلزم قياس الكتلة وCG والتحقق من بيانات المحرك والظروف ومقارنة التوقعات برحلات مقاسة قبل الاعتماد الهندسي المتقدم.

للتفاصيل العلمية وحدود التحقق، راجع [Physics verification report](https://github.com/gherablimanar/Hoshi/blob/main/docs/physics-validation.md).
