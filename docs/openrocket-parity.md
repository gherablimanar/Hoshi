# OpenRocket 24.12 compatibility ledger

**Full parity is not achieved.** The browser application is an independent interface. Core reuse alone does not verify an adapter or workflow. Status applies only to the specific behavior and evidence stated in each row. This document retains the full requested scope.

Baseline: source tag `release-24.12`, exact commit `133b558de556f0282f51c3f53f3b3fc633b4310a` confirmed with `git ls-remote`. Component database submodule: `1512874ace50917e25ccf7d7df1f616b5f39a8b5`. Motor database: the serialized thrust curves shipped in that same core tree. No `--remote` submodule updates. No latest-release data is merged.

## Numerical acceptance

Tolerances were declared in `tests/tolerances.json` **before** generating and assessing references. `ReferenceGenerator.java` calls the pinned upstream loader and simulation directly. `EngineTest` compares the adapter round trip to those references, including mass/CG/CP, flight metrics, warning strings and every branch event sequence/time. `tests/reference.json` records six cases. `tests/comparison-results.json` is only a successful current-run report when its generation is recorded in test evidence. Do not regenerate references to hide adapter failures.

Deterministic fixtures explicitly set average wind and deviation to zero and seed to 24012. The upstream public API does not expose all wind-model RNG seeds. Turbulent wind parity needs appropriate statistical checks; it is not verified by the deterministic cases.

## Output-series extension

The reference files now also contain every available variable for every branch. Existing reference mass/CG/CP, summaries, warnings and event sequences/times were checked unchanged when sample vectors were added. Current comparison report includes 596 numerical comparisons (140 scalar/event comparisons and 456 variable-series comparisons), covering 143,013 finite/masked samples, with maximum observed absolute difference 0 on this Linux/JDK toolchain. Eight `tc` series are checked structurally instead: upstream `SimulationStatus` explicitly writes `(System.nanoTime() - getSimulationStartWallTime()) / 1e9`. That wall-clock telemetry is not a deterministic flight quantity. It is still exported; physical tolerances were not widened to absorb it.

Native component inventory smoke coverage uses each registered family with an upstream-compatible parent, checks UUID/name/comment/hierarchy/class through `.ork` save/load, and verifies editable metadata. This is default-family round-trip evidence, not exhaustive verification of every property combination. Source-only Sleeve is not exposed because the pinned native reader does not register a sleeve constructor.

## Hosted browser access

The GitHub Pages/hosted-engine adapter is implemented separately from engineering parity: `/Hoshi/` static asset routing, configurable HTTPS engine, memory-only owner access password, authenticated imports/downloads and exact-origin CORS. The local evidence is in `docs/hosting-validation.md`. Two hosted browser journeys and the original three local journeys passed. Real public deployment remains unverified until Pages is enabled and an owner creates the hosting service. Free Render files are temporary and the UI explicitly advises exports; this does not claim durable cloud storage across restarts or multi-user tenancy.
